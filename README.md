# 💰 Expense Engine – Smart Cloud-Based Expense Tracker

A modern, cloud-powered expense tracking web application built using **Vanilla JavaScript + Firebase**.  
It provides real-time analytics, interactive charts, authentication, and financial insights — all without a traditional backend server.

## 🚀 Live Demo
https://logeshk48.github.io/Expense-tracker/index.html

## 📌 Overview

Expense Engine is a serverless financial tracking application designed to help users:

- Track daily expenses
- Analyze spending patterns
- Monitor monthly trends
- Gain intelligent financial insights

It uses **Firebase (Backend-as-a-Service)** to handle authentication and database operations securely.

## 🏗 Architecture

This project follows a Serverless Architecture Model:

Frontend (HTML / CSS / JS)
        ↓
Firebase Authentication
        ↓
Firestore Database (Cloud)

✔ No Node.js  
✔ No Express  
✔ No Custom Backend Server  

Everything runs on Firebase infrastructure.
