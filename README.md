# Expense Tracker

Premium glass-style fintech expense tracker (HTML/CSS/JS) deployed on GitHub Pages.

## Features
- Login with Name + PIN (saved locally)
- Add / Edit / Delete expenses
- Today / Week / Month / Year totals
- Category distribution + 7-day trend charts
- Reports with filters
- Mobile responsive UI
- Data stored in LocalStorage

## Tech Stack
- HTML
- CSS (Glass UI)
- JavaScript
- Chart.js

## Future Improvements
- Cloud DB (Firebase/Supabase)
- User accounts across devices
- AI insights + chatbot
